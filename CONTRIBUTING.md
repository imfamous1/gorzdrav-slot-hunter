# Как внести изменения

1. Запусти `./scripts/setup.sh` с Python 3.11 или новее.
2. Проверь изменения командой `.venv/bin/python -m unittest discover -s tests -v`.
   Тесты используют подставные ответы, поэтому профиль и Telegram не нужны.
3. В pull request опиши, какой сценарий меняется и как его проверить. Если
   меняется команда или параметр, обнови README и пример конфигурации.

Для воспроизведения ошибки используй вымышленные данные. При добавлении
сетевых сценариев сохраняй последовательный опрос и ограничение частоты.

## Запуск и сборка настольного приложения

Для запуска окна из исходников установи зависимости из
`requirements-desktop.txt` и запусти `python desktop_app.py`.
Интерфейс использует PySide6 и Qt Quick. С этими зависимостями набор
`python -m unittest discover -s tests -v` проверяет и окно приложения.

Для архива установи зависимости сборки и запусти упаковку на нужной ОС.

```bash
python -m pip install -r requirements-build.txt
python packaging/build_desktop.py
```

GitHub Actions собирает Windows x64 и macOS для Apple Silicon и Intel.
На каждой платформе проверяются отступы, переключение вкладок и
восстановление активного поиска. Скрипт сборки запускает упакованное
приложение и проверяет комплектный сертификат. Архивы создаются в `dist/`.
В публикуемые архивы добавляются тексты лицензий Qt и уведомление со
ссылками на соответствующие исходники, как в [релизе v1.2.0](https://github.com/imfamous1/gorzdrav-slot-hunter/releases/tag/v1.2.0).

Для встроенного обновления сначала обнови `__version__`, собери три ZIP и
добавь тексты лицензий. Затем подпиши манифест финальных архивов:

```bash
python packaging/sign_update.py --key /path/to/update-ed25519.key /path/to/final-zips
```

Загрузи три ZIP, `update-manifest.json` и `update-manifest.sig` в один
релиз GitHub с тегом `v<версия>`. Публикуй релиз после загрузки всех файлов.
Подпись связывает имя, размер и SHA-256 каждого архива с тегом релиза.
Храни закрытый ключ вне репозитория. Приложение содержит только открытый ключ.

Данные настольной версии находятся в `%LOCALAPPDATA%\GorzdravSlotHunter` на
Windows и `~/Library/Application Support/Gorzdrav Slot Hunter` на macOS.
Для изолированных прогонов можно указать другой каталог через
`GORZDRAV_HOME`.
