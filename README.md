# Талоны Горздрава

Приложение ищет свободные талоны на Горздраве Санкт-Петербурга, записывает
пациента на подходящий приём или переносит действующую запись. Можно
запустить несколько поисков и получать уведомления в Telegram.

Сборки для macOS распространяются без нотариализации Apple, а сборка для

## Обновление приложения

Номер версии виден внизу боковой панели. Приложение проверяет GitHub при
запуске. Нажми номер версии, чтобы проверить вручную или скачать и
установить доступное обновление. Во время установки окно перезапустится.
Сохранённые профили и настройки будут доступны после обновления, а
активный поиск возобновится. Версию 1.3.0 нужно установить вручную поверх
предыдущей один раз.

## Как искать талон

1. В разделе **Пациенты** добавь профиль с именем, фамилией и датой рождения.
2. В разделе **Поиск** выбери район, поликлинику, специальность и врача.
   Если врач не важен, выбери **Любой врач**. Списки можно фильтровать по
   названию, адресу или номеру.
3. Выбери пациента и режим **Автозапись** для нового приёма или
   **Автоперенос** для существующего. Для переноса нажми **Найти запись**
   и выбери исходный приём. Кнопка со знаком вопроса открывает пояснение к режиму.
4. Укажи один день, диапазон или только начальную дату. При переносе поиск
   должен начинаться позже даты исходного приёма. Можно ограничить время
   начала приёма на каждый день, например до 12:00. Ограничение может
   снизить шансы поймать талон.
5. Нажми **Запустить поиск** и подтверди действие. Приложение проверит
   медкарту пациента в выбранной поликлинике, прежде чем искать талоны.

Кнопка **+ Новый поиск** открывает отдельную вкладку. Каждый поиск можно
запустить и остановить отдельно. Во вкладке видно состояние и время
последней проверки. Кнопка **Проверить прикрепление** доступна до запуска
поиска и открывает сервис Горздрава. Если Горздрав откажет в записи из-за
данных о прикреплении по ОМС, причина появится во вкладке поиска.

Активный поиск работает в фоне после закрытия окна, пока компьютер
включён и подключён к интернету. При повторном открытии приложение
восстанавливает активные задачи и переносы, которые ждут подтверждения
Горздрава. Черновики и остановленные задачи закрываются вместе с окном.
После выключения компьютера или выхода из системы запусти поиск заново.

## Мои записи

Раздел **Мои записи** загружает с Горздрава предстоящие талоны сохранённых
пациентов в поликлиниках из их поисков и ранее найденных медкарт. На каждой
карточке указаны дата и время приёма в Санкт-Петербурге, пациент, врач и
поликлиника. Кнопка **Открыть Горздрав** ведёт в личный кабинет портала.

**В календарь** открывает событие `.ics` с напоминанием за час. Подтверди
импорт в календаре. Если отменишь или перенесёшь приём, обнови событие в
календаре вручную.

**Отменить** отправляет запрос только после подтверждения. Приложение
проверяет, исчез ли талон из списка Горздрава. Для записей по направлению
открывается сервис отмены на портале.

## Telegram

Уведомления в Telegram включаются по желанию. Создай бота через BotFather,
нажми **Start** в его чате и укажи токен и числовой ID чата во вкладке
**Telegram**. Нажми **Сохранить**, чтобы применить настройки при следующем
запуске фонового процесса. Кнопка **Отправить тест** проверяет настройку.
[BotFather](https://t.me/BotFather) · [Как получить ID чата через getUpdates](https://core.telegram.org/bots/api#getupdates)

## Данные и исходный код

Профили, настройки, токен и история хранятся в каталоге данных приложения.

- Windows: `%LOCALAPPDATA%\GorzdravSlotHunter`
- macOS: `~/Library/Application Support/Gorzdrav Slot Hunter`

Приложение передаёт данные пациента Горздраву для поиска его записей,
автозаписи, переноса и отмены. Если уведомления включены, Telegram получает текст
уведомления.

Терминальная версия использует тот же движок поиска и хранит настройки и
профили отдельно. В её справке описаны расширенные настройки и фоновый
запуск через `launchd`.
