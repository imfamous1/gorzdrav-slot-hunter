# Gorzdrav Slot Hunter

Скрипт отслеживает свободные талоны на портале Горздрава Санкт-Петербурга.
Можно посмотреть расписание, получать уведомления в Telegram и включить
автоматическую запись на ближайший подходящий талон.

## Быстрый старт

Нужны Python 3.11 или новее, Git и Bash. Приложение работает в терминале
на macOS и Linux.

```bash
git clone https://github.com/imfamous1/gorzdrav-slot-hunter.git
cd gorzdrav-slot-hunter
./scripts/setup.sh
./hunt.sh explore
./hunt.sh slots
```

Команда `explore` предложит выбрать район, поликлинику, специальность,
врача и даты. Чтобы искать у всех врачей выбранной специальности,
оставь поле с идентификаторами пустым. Начальная дата включается в поиск.
Пустая конечная дата означает любое доступное время начиная с выбранного дня.

После пробного просмотра запусти `./hunt.sh` для регулярного опроса.
В новом конфиге автозапись и Telegram выключены. Текущие параметры и время
последнего успешного опроса показывает `./hunt.sh status`.

## Telegram

1. Создай своего бота через [BotFather](https://t.me/BotFather) и нажми
   **Start** в чате с ним.
2. Заполни в `config.json` поля `telegram.bot_token` и `telegram.chat_id`,
   затем установи `telegram.enabled` в `true`.
3. Выполни `./hunt.sh test-telegram`. В чат должно прийти тестовое сообщение.

Идентификатор чата есть в поле `message.chat.id` ответа метода
`getUpdates` после сообщения боту. Вставляй токен только в локальный
конфиг или в HTTPS-запрос к официальному API Telegram.
[Документация Telegram Bot API](https://core.telegram.org/bots/api#getupdates)

Сообщения о перезапуске идут в локальный журнал. В Telegram приходят
подходящие талоны в режиме наблюдения и результаты попыток записи,
предусмотренные приложением.

## Запись на приём

Для записи скопируй `profile.example.json` в `profile.json` и заполни
`last_name`, `first_name`, `birthdate` в формате `ДД.ММ.ГГГГ`.
При наличии отчества укажи `middle_name`. Поля `email` и `phone`
необязательны. Если указан телефон из десяти цифр, скрипт после успешной
записи попытается обновить его в медкарте.

- **Вручную.** Выполни `./hunt.sh slots`, затем `./hunt.sh book 1`, подставив
  номер нужного талона. Скрипт покажет карточку и спросит подтверждение.
  Номера действуют 15 минут после последнего просмотра.
- **Автоматически.** Включи `auto_book.enabled` в `config.json`. В терминале
  можно подтверждать каждую запись. Для фоновой автозаписи требуется
  `consent_booking: true` в профиле. При нескольких подходящих талонах
  скрипт выбирает самый ранний из доступных на момент опроса.

Скрипт подтверждает запись после проверки списка приёмов на портале.
Если там уже есть активная запись к той же специальности, портал может
отклонить новую. Скрипт не отменяет действующие записи.

## Настройки

`./hunt.sh explore` добавляет новую цель в `config.json`. Чтобы отредактировать
существующую, поправь соответствующий элемент массива `targets`.
После изменения настроек перезапусти опрос.

| Поле | Что задаёт |
| --- | --- |
| `poll_interval_sec` | Пауза между циклами. По умолчанию 60 секунд, минимум 30. |
| `http.timeout_sec` | Тайм-аут запроса к Горздраву в секундах. |
| `http.sleep_between_requests_sec` | Пауза между последовательными запросами. Минимум 1 секунда. |
| `http.direct_interface` | Сетевой интерфейс macOS для прямого подключения к Горздраву. `null` использует обычный маршрут. |
| `http.insecure_tls` | Проверка TLS выключается при `true`. Оставляй `false` при работе с профилем. |
| `targets[].book_date_from` | Первая подходящая дата, включительно. Формат `ГГГГ-ММ-ДД`. |
| `targets[].book_date_to` | Последняя подходящая дата, включительно. `null` открывает диапазон. |
| `targets[].specialty_ids` / `specialty_name_contains` | Выбор специальности по ID или по части названия. Достаточно совпадения одного фильтра. |
| `targets[].doctor_ids` | Ограничение по врачам. Пустой список включает всех врачей выбранных специальностей. |
| `auto_book.enabled` | Автозапись по умолчанию. `targets[].auto_book` переопределяет её для одной цели. |
| `auto_book.stop_after_booking` | Завершить фоновый цикл после подтверждённой записи. |
| `auto_book.stop_if_same_specialty` | Проверять существующую запись к той же специальности перед попыткой. Отдельная цель может переопределить значение. |
| `targets[].notify_out_of_window` | Показывать в терминале найденные талоны вне окна. |
| `heartbeat_hours` | Интервал между сообщениями о работе в терминале. `0` отключает их. |
| `notify.desktop_notification` | Уведомление macOS после подтверждённой записи. |

## Фоновый запуск на macOS

```bash
./scripts/install_launchd.sh
tail -f logs/hunter.log
```

Скрипт запускается при входе в macOS и перезапускается после аварийного
выхода. После штатной остановки агент можно запустить снова командой
`launchctl kickstart "gui/$(id -u)/ru.spb.gorzdrav.hunter"`. Если работаешь
вручную через `slots` или `book`, сначала останови фоновый экземпляр.

```bash
./scripts/uninstall_launchd.sh
```

Если Горздрав недоступен через VPN, укажи имя Wi‑Fi или Ethernet в
`http.direct_interface`. Например, `"en1"`, если именно так называется твой
Wi‑Fi. Имена показывает `networksetup -listallhardwareports`. Настройка
применяется к IPv4-запросам скрипта на `gorzdrav.spb.ru`.

## Справка по командам

| Команда | Действие |
| --- | --- |
| `./hunt.sh explore` | Добавить цель интерактивно. |
| `./hunt.sh slots` | Получить текущие талоны и сохранить их номера для ручной записи. |
| `./hunt.sh` или `./hunt.sh hunt` | Запустить опрос. |
| `./hunt.sh hunt --once --dry-run` | Один пробный опрос с выводом в терминал, без записи и обновления истории. |
| `./hunt.sh book N` | Подтвердить выбранный талон из последнего просмотра. |
| `./hunt.sh status` | Цели, состояние и время последнего успешного опроса. |
| `./hunt.sh test-telegram` | Отправить тестовое уведомление. |
| `./hunt.sh forget` | Удалить локальный профиль, историю и список талонов после подтверждения. |

## Приватность

`config.json`, `profile.json`, `state.json` и журналы содержат локальные данные
и исключены из Git. Данные профиля отправляются на Горздрав при обращении
к медкарте и записи. Уведомления Telegram содержат информацию о талоне и
поликлинике, поэтому используй личный чат.

Для TLS клиент добавляет корневой сертификат НУЦ Минцифры к бандлу
`certifi` только в процессе приложения. При запуске проверяется SHA‑256
вложенного PEM-файла. Системное хранилище не меняется.
[Источник сертификата](https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt)

## Ограничения и участие

Приложение использует неофициально описанный API Горздрава. Доступность
записи, прикрепление и правила повторной записи определяет портал.
Для личного использования запускай один экземпляр и выбирай только нужную
поликлинику и специальность. При сбоях скрипт увеличивает паузу между опросами.

При разработке пригодилось публичное описание API.
[spb-gorzdrav-skill](https://github.com/cucumberian/spb-gorzdrav-skill)
