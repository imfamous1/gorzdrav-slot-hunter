# Талоны Горздрава

Настольное приложение ищет свободные талоны на портале Горздрава
Санкт-Петербурга. Можно следить за талонами или разрешить приложению
записать на первый подходящий приём.

## Скачать и открыть

| Компьютер | Как открыть |
| --- | --- |
| **Windows 10/11, x64** | Скачай архив с пометкой `Windows-x64`, распакуй его целиком и запусти `GorzdravSlotHunter.exe` из папки. |
| **Mac, Apple Silicon** | Скачай архив с пометкой `macOS-arm64`, распакуй и перенеси приложение `GorzdravSlotHunter.app` в «Программы». |
| **Mac, Intel** | Скачай архив с пометкой `macOS-x64`, распакуй и перенеси приложение в «Программы». |

[Скачать последнюю версию](https://github.com/imfamous1/gorzdrav-slot-hunter/releases/latest)

Модель процессора Mac можно посмотреть в меню Apple → «Об этом Mac».
Сборки для macOS пока без нотариализации Apple, а для Windows без подписи
издателя. Система может показать предупреждение при первом открытии.
[Как macOS проверяет загруженные приложения](https://support.apple.com/102445)

## Как искать талон

1. Если поиск привязан к человеку, добавь его во вкладке **Пациенты**.
2. Во вкладке **Поиск** выбери район, поликлинику, специальность и врача.
   Можно выбрать **Любой врач**.
   Введи часть названия, адреса или номера, чтобы отфильтровать список.
   Укажи один день, диапазон или начальную дату.
3. Выбери **Автозапись** или **Автоперенос** и укажи сохранённого пациента.
   Нажми **ⓘ** рядом с режимом, чтобы прочитать пояснение. В режиме
   переноса нажми **Найти запись** и выбери действующий приём.
4. Нажми **Запустить поиск** в выбранной вкладке. Чтобы создать ещё один
   поиск, нажми **+ Новый поиск**. У каждой вкладки свои даты, врач,
   пациент и время последнего опроса. Приложение сохраняет задачу при
   запуске. После закрытия окна черновики и остановленные задачи
   исчезают из панели вкладок.
5. После закрытия окна поиск продолжится.
   При следующем открытии приложение покажет режим и время последнего опроса.

Новый поиск можно настроить и запустить во время работы других задач.
Он подключится со следующего опроса.

Результаты и сообщения о записи сохраняются во вкладке **История**.
Кнопка **Остановить поиск** действует на выбранную вкладку.
Компьютер должен быть включён и подключён к интернету. После выключения
или выхода из системы поиск можно запустить снова из приложения.

Горздрав определяет доступность талонов и проверяет прикрепление. Успешная
запись появляется в истории после сверки с порталом.

## Telegram

Уведомления в Telegram включаются по желанию. Создай бота через BotFather,
нажми **Start** в его чате и укажи токен и числовой ID чата во вкладке
**Telegram**. Нажми **Сохранить**, чтобы применить настройки при следующем
запуске фонового процесса. Кнопка **Отправить тест** проверяет настройку.
[BotFather](https://t.me/BotFather) · [Как получить ID чата через getUpdates](https://core.telegram.org/bots/api#getupdates)

## Данные и исходный код

Профиль, настройки, токен и история хранятся в каталоге данных пользователя
на компьютере. Профиль передаётся Горздраву при записи. Telegram получает
текст уведомления, если эта опция включена.

Настольное приложение использует тот же движок поиска, что и терминальная
версия. Профили этих двух способов запуска хранятся отдельно. Расширенные настройки переноса описаны в справке терминальной версии.
