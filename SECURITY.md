# Сообщения об уязвимостях

Для приватного сообщения используй **Report a vulnerability** на вкладке
[Security](https://github.com/imfamous1/gorzdrav-slot-hunter/security).
Укажи версию, затронутую команду и минимальный пример с вымышленными данными.

В баг-репорты и PR включай только обезличенный фрагмент лога. Токен Telegram,
профиль пациента, файл состояния и записи на приём храни локально. Если токен
бота стал публичным, отзови его через BotFather.
