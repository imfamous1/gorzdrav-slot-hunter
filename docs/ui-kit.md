# UI-кит настольного приложения

Оболочка работает на PySide6 и Qt Quick Controls в общем стиле Basic.
Цвета заданы в [Theme.js](../gorzdrav_hunter/qml/Theme.js). Кнопки, карточки,
поля и меню выбора используют общие QML-компоненты.
За иконки интерфейса отвечает `Icon.qml`. SVG-файлы Lucide 1.77.0 и
лицензия лежат в `gorzdrav_hunter/qml/icons`. Имена в `glyph`
соответствуют названиям файлов.

- Рабочая область белая, боковая навигация тёмно-синяя. Синий акцент
  выделяет выбранный режим, открытую вкладку и активный поиск.
- Карточки имеют скругление 18 px, кнопки и поля около 44 px в высоту.
  Контуры рисует Qt Quick с учётом масштаба экрана.
- На широком окне параметры поликлиники и дат находятся рядом с режимом
  и пациентом. В узком окне карточки встают друг под другом и прокручиваются.

| Элемент | Поведение |
| --- | --- |
| Навигация | Активный раздел выделен, кнопки доступны с клавиатуры. |
| Вкладки | «Новый поиск» открывает черновик до закрытия окна. Подтверждение запуска сохраняет задачу. При повторном открытии восстанавливаются активные задачи и переносы, ожидающие подтверждения Горздрава. |
| Режимы | «Автозапись» и «Автоперенос». Кнопка со знаком вопроса открывает пояснение. Escape и клик вне подсказки её закрывают. |
| Каталог | Поиск по названию, адресу или номеру. Стрелки двигают выбор, Enter выбирает, Escape закрывает. |
| Даты | При диапазоне видны оба поля. Ошибка отмечает нужное поле. |
| Статус | Текст и цвет показывают состояние, рядом отображается время последней проверки. |
| Запись | Исходный приём загружается по кнопке и виден во время работы. Запуск автозаписи или автопереноса требует подтверждения. |
| Пациенты | Профиль выбирается из списка. Добавление и сохранение находятся в разделе «Пациенты». |
| Telegram | Переключатель, скрытый токен, ID чата и отдельный тест отправки. |
| Мои записи | Предстоящие приёмы показывают время, врача, поликлинику и пациента. Доступны переход в Горздрав, экспорт в календарь и отмена с подтверждением. |

Для проверки используй отдельный каталог данных и пробные профили.
Проверь оба режима, пустой каталог, ошибки формы, черновик, остановку
и повторное открытие окна с действующим поиском.
